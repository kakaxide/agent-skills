# 你必须遵守

以下条款为命令式，优先级高于本文件其它内容：

1. **讲解必须结合图**。成功提取的论文原图要放进 HTML 对应章节，图下紧跟图解，用图解释正在讲的内容。图和文不许分离成两个独立区域。
2. **讲解中的任何数字必须来自论文原文文本，禁止从图中估读数值，禁止编造。**
3. **宁缺毋滥**：看不清、讲不准的图，只放图不放讲解；提取失败的图直接不放。不留任何猜测性文字。
4. **多模态阀门**：开始讲解前必须自检能否理解图像内容。非多模态模型必须停下询问用户（切换模型或确认降级），用户确认后才继续；降级产出的 HTML 顶部必须显著标注"非多模态生成"。
5. **语言朴素可靠**：简单、清晰、直击本质。不堆砌模板腔，不打蹩脚比方，不空话套话。

## 工作流

### 第 1 步：提取全文与图

```bash
python scripts/extract.py --input 论文.pdf --workdir 解析输出目录
python scripts/extract.py --input 论文.docx --workdir 解析输出目录
```

产出：

```
<workdir>/
├── fulltext.txt      # 全文文本，含图题行及 [FIGURE:fig_XXX] 位置标记
├── figures.json      # 每张图的元数据：图题、页码、提取通道、置信度
└── figures/          # 论文原图 PNG（fig_001.png ...）
```

PDF 提图依赖 pymupdf（未安装时脚本报缺失提示，此时告知用户需要安装，不得擅自跳过）。Word 提图用标准库 zipfile。

### 第 2 步：多模态阀门（强制检查点）

从 `figures/` 取一张图尝试视觉理解，然后分支：

- **能理解图像** → 图文模式：逐图阅读，撰写图文混排讲解。
- **不能理解图像** → **停下，询问用户**，二选一：
  1. 切换多模态模型后继续（推荐，图讲解完整）；
  2. 用当前模型降级继续：图照放，图解仅依据图题原文与正文上下文，HTML 顶部显示非多模态警告条，每个图解块角标标注「依据：图题与正文」。

  用户未确认前不得继续，不得擅自降级。

### 第 3 步：撰写讲解

通读 fulltext.txt，按三段式撰写内容文件 `content.md`：

```
---
title: 论文标题
authors: 作者（可省略为 et al.）
year: 年份
oneliner: 一句话总结（这篇论文做了什么、做到了什么程度）
mode: multimodal   # 或 text-only
---

## 1. 背景与动机
（现有方法缺什么、为什么这个问题值得做；引用 Fig.1 问题示意图处写 ![fig_001](figures/fig_001.png)）

## 2. 方法
（核心思路 + 关键步骤；架构图/流程图嵌在对应步骤文字之后）

## 3. 实验效果
（关键数字 + 与基线对照；结果图表嵌在对应结论文字之后）
```

图文混排规则：

- 图放在**它解释的那段文字之后**，紧跟一段"图解：……"（2~5 句话），不许把所有图堆到文末。
- 图解只讲这张图本身说明了什么、和上下文结论的关系。
- 引用图用 markdown 图片语法 `![fig_XXX](figures/fig_XXX.png)`，文件名以 figures.json 为准。
- 附录（可选）：`## 附录：图表总览`，未在正文用到的图放缩略 + 图题一行。

语言风格要求（对齐"朴素可靠简单直击本质"）：

- 短句为主，先说结论再说细节；一段只说一件事。
- 禁止：机械模板腔（"首先…其次…综上所述"的空洞串联、"值得注意的是"、"不难发现"）、蹩脚比喻（"就像…"式类比除非原文有）、空话（"具有重大意义"、"效果显著"无数字支撑）。
- 允许：直接引用论文自己的表述做转述；用数字说话；承认论文的局限。
- 术语保持论文原文用法，首次出现给一句朴素解释。

### 第 4 步：生成 HTML

```bash
python scripts/build_html.py --content content.md --workdir <workdir> --out 论文讲解.html
```

产出单文件 HTML：论文原图 base64 内嵌、离线可开、低饱和学术风。自检后再交付：

- [ ] 每个内嵌图下方有图解（或按宁缺毋滥规则留白）
- [ ] 数字全部能在 fulltext.txt 中找到出处
- [ ] mode 为 text-only 时顶部警告条存在
- [ ] 本地打开 HTML 图片正常显示

## 防幻觉与降级细则

| 情况 | 行为 |
|---|---|
| 图清晰、模型有把握 | 图解正常撰写，角标 `Fig.N (p.X)` |
| 图复杂、无把握 | 只放图 + 图题，不写图解 |
| 非多模态模式 | 图解只允许复述图题与正文相关内容，角标「依据：图题与正文」 |
| 图提取失败或低置信 | 不进 HTML，正文不提"如图所示" |
| 某章节无对应图 | 纯文字讲解，不硬凑图 |

严禁事项：

- ❌ 编造图中不存在的曲线、数据点、对比结果
- ❌ 从图中目测估读具体数值写进讲解
- ❌ 把所有图堆在文末形成"图廊"，与正文脱节
- ❌ 非多模态时擅自继续而不询问用户
- ❌ 用 AI 生成图替代论文原图（本 Skill 只用论文原图）

## 依赖

- Word 解析与 HTML 生成：仅 Python 标准库
